## Acerca de
Este pequeño proyecto CLI se elaboró para probar mi conocimiento sobre el módulo random. Las contraseñas generadas no se almacenan.

## Dependencias
* Python 3.14.7

## Uso
1. Descargar la versión más reciente de [Python](https://www.python.org/downloads/).
2. Clonar el repositorio.
```
git clone https://github.com/Andyy10/contraneitor.git
```
3. En una terminal (CMD, Terminal, Powershell) ejecutar el archivo main.py que se encuentra en la carpeta 'src'.
```
cd src
python main.py
```
4. Ingresar en la terminal los datos que se piden.

## Estructura del proyecto
```text
contraneitor: Generador de contraseñas.
├── src: Archivos necesarios para que el proyecto funcione.
│   ├── main.py: Programa principal donde se maneja la lógica del programa.
│   └── arte_contraneitor: Logotipo ASCII del programa.
└── docs: Documentación del proyecto e imágenes.
```
